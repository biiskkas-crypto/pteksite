# pteksite

Página estática com botão de atendimento pelo WhatsApp.

## Configuração

O número está configurado no arquivo `index.html` no formato internacional, sem
espaços ou símbolos: `351928124737`. Para alterar o contato, substitua o número
nas duas URLs `https://wa.me/...` e atualize a mensagem após `text=`.

Abra `index.html` diretamente no navegador ou publique os arquivos em qualquer
serviço de hospedagem estática.
